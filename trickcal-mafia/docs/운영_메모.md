- 베타 진행 중에는 배포하지 않기

## Cloudflare 무료 한도 주의 (베타 전 필수 확인)
- 한도를 넘으면 그 순간 요청이 **오류로 실패** → 게임이 멈춘다
- 대략적인 계산 (2026-10 문서 기준, 바뀔 수 있음):
  - 요청: 하루 10만. 들어오는 웹소켓 메시지는 20개 = 요청 1개로 계산
    - 12명이 광장에서 계속 걸으면 방 하나당 1시간에 약 2.4만 요청 → **하루 약 4 방-시간이면 한도**
  - 연결 시간: 하루 13,000 GB-s ≈ 방 28개 × 1시간
- 베타 당일: 대시보드에서 그날 사용량 먼저 확인
- 할 일 후보: 이동 신호 전송 빈도를 절반으로 줄이기, 사람/봇 사용량 구분 계측

## VPS 이전 계획 (필요해지면)
- 후보: Tencent Lighthouse (2코어 4GB, 첫해 특가 약 10달러 — **2년 차부터 정가 갱신**, 결제 전 갱신가 확인)
  - 오라클 무료 서버는 가입 승인·리전 자리·회수 문제로 메인으로는 불안
- **구성: 도메인을 사서 Cloudflare에 연결** (Cloudflare에서 구매하면 원가, .com 연 1만 5천 원 안팎)
  - Cloudflare 무료 플랜으로 VPS 앞단 보호(디도스 방어·실제 주소 숨김·HTTPS) — 추가 비용 없음
  - VPS 연결은 Cloudflare Tunnel(무료) 또는 프록시
  - 화면(그림·음악 파일)은 계속 Cloudflare에서 무료로 내보내고, 게임 서버만 VPS
  - 무료 주소(duckdns 등)는 Cloudflare에 못 올려서 보호를 직접 해야 함 → 쓰지 않기로
- 1년 총비용 예상: VPS 약 10달러 + 도메인 약 1만 5천 원
- 처음 한 번 세팅 필요(하루이틀): Node 게임 서버, 자동 재시작, 배포 스크립트 / 서버 접속(SSH) 작업 일부는 직접

## 버그 제보 보는 법
- 게임 안 🐞 버튼으로 들어온 제보는 두 곳에 남는다
  1. **Cloudflare 대시보드 → Workers → trickcalchibigo → 로그**: `report` 로 검색 (며칠만 보관)
  2. **제보 목록 페이지**: `https://(사이트 주소)/api/reports?key=비밀열쇠` — 최근 1000개, 상황(방·단계·직업·최근 기록·오류)까지
     - 처음 한 번: 대시보드 → Workers → trickcalchibigo → 설정 → 변수 및 비밀 → **비밀(Secret)** 로 `REPORT_KEY` 추가 (아무 긴 문자열)
     - 설정 안 하면 목록 페이지는 막혀 있고 로그로만 볼 수 있다
