# UI·에셋 목록

게임 화면은 **1920×1080 (16:9)** 기준으로 만들어져 있고, 창 크기에 맞춰 통째로 확대·축소됩니다.
UI 이미지도 이 크기 기준으로 만들면 됩니다.

**모든 이미지는 없어도 게임이 돌아갑니다.** 없으면 색 상자나 "배경 없음" 같은 임시 표시가 뜹니다.
만드는 대로 하나씩 넣으면 바로 반영돼요.

## 1. 캐릭터

```

    panic.gif
    angry.gif

  joan/ …
```

| --- | --- | --- | --- | --- |
| `kyoju` | 교주 | | `daya` | 다야 |
| `erpin` | 에르핀 | | `sila` | 실라 |

- 감정 파일 이름은 `characters.yaml` 의 `emotion_aliases` 오른쪽(영문)과 같게. 감정을 추가하면 번역표에도 추가
- 권장 높이: 화면 높이의 90% 정도 (약 1000px). 발끝(또는 화면 아래 잘리는 선)이 그림 맨 아래에 오게
- 확장자는 `config.yaml` 의 `characters.ext` 로 한 번에 바꿀 수 있어요 (`gif` / `webp` / `png`)

### GIF 테두리(헤일로) 문제

GIF 투명도는 켜짐/꺼짐 두 단계뿐이라 어두운 배경에서 외곽에 흰 테두리가 보일 수 있어요.
애니메이션 WebP 로 바꾸면 부드러운 투명도를 쓸 수 있습니다. [ffmpeg](https://ffmpeg.org/) 가 있으면 폴더 통째로 변환:

```bash
# public/assets/characters 안에서 (macOS·Linux·Git Bash)
for f in */*.gif; do ffmpeg -y -i "$f" -loop 0 -lossless 1 "${f%.gif}.webp"; done
```

변환 후 `config.yaml` 의 `characters.ext` 를 `webp` 로 바꾸면 끝입니다.
(원본 GIF 자체의 흰 테두리는 변환해도 남으니, 가능하면 원본을 배경 없이 다시 뽑는 게 가장 좋아요)

### 배경 속 문·계단 (`exits`)

`locations.yaml` 에서 방마다 `exits` 로 **배경 그림 속 문 위치**를 적으면, 그 자리를 눌러 이동합니다.
누를 수 있는 곳에는 금빛 점이 숨 쉬듯 깜빡이고, 누르면 연출이 나옵니다.

| kind | 연출 |
| --- | --- |
| `zoom` | 그 문 쪽으로 확대되며 어두워짐 → 새 방이 살짝 크게 시작해 제자리로 |
| `stairs_up` / `stairs_down` | 발소리와 함께 화면이 위아래로 흔들리며 오르내림 |
| `left` / `right` | 옆으로 걸어가듯 밀려남 |
| `fade` | 그냥 암전 |

`kind` 를 비우면 층이 다르면 계단, 같으면 확대로 자동 선택. 배경을 새로 그리면 문 위치(`rect`)를 디버그(F9) → 조사 지점 테두리 보기로 맞추세요.

- 크기 1920×1080, 용량을 줄이려면 jpg 또는 webp
- 조사 지점 위치(`rect`)는 배경 그림 위의 % 좌표라, 배경을 바꾸면 위치도 다시 확인하세요 (디버그 → 조사 지점 테두리 보기)

### 방탈출 그림

```
public/assets/closeup/이름.jpg   ← 클로즈업 화면 (찻잔 속, 서랍 안 …). 조사 파일 closeups 의 image
public/assets/items/이름.png     ← 아이템 그림 (items.yaml 의 image). 정사각형 256×256 정도
public/assets/bg/방_night.jpg    ← 같은 방의 밤·변한 버전 (조사 파일 bgs 로 바꿔 끼움, 사진 비교에 사용)
public/assets/ui/map_1.png       ← 층별 지도 (map_1, map_2, map_-1, map_attic …). 없으면 map.png
```

- 클로즈업 그림이 없으면 적어 둔 설명 글이 대신 뜹니다. 필요한 것만 그리면 돼요.
- 클로즈업은 16:9 로 만들면 화면에 꽉 찹니다.

## 5. 엑스트라 (CG · 음악 · 영상)

`content/extras.yaml` 에 목록을 적으면 타이틀의 **엑스트라**와 게임 중 메뉴에 나옵니다.

- **CG**: `public/assets/cg/` 의 그림. 게임에서 `#cg:이름` 으로 한 번 보면 열림
- **음악**: `public/assets/bgm/` 의 곡. 게임에서 한 번 들으면 열림. 원판 그림은 `art:` 로 따로 줄 수 있음 (없으면 타이틀 그림)
- **영상**: `public/assets/` 기준 파일 이름 (.webm / .mp4)
- 타이틀 음악은 `bgm/title.mp3` (config.yaml 의 `title_bgm` 으로 이름 변경 가능)

## 6. UI 이미지

**UI 는 그림 없이 코드로 그립니다** (반투명 유리판 + 가는 선 + ✦ 장식).
색·글꼴·크기는 `src/styles/theme.css` 의 변수만 바꾸면 전체에 반영돼요.
글꼴은 본문 Pretendard, 제목 Noto Serif KR 이고 `index.html` 에서 불러옵니다.

그림으로 필요한 건 아래뿐입니다.

| 파일 (public/assets/ui/) | 권장 크기 | 쓰이는 곳 |
| --- | --- | --- |
| `title_bg.jpg` | 1920×1080 | ✅ 타이틀 배경 (영상이 뜨기 전 첫 장면) |
| `title_bg.webm` / `title_bg.mp4` | 1920×1080, 소리 없음 | ✅ 타이틀 움직이는 배경 (반복 재생) |
| `favicon.png` | 64×64 | 브라우저 탭 아이콘 |
| `map.png` | 1200×700 | 저택 지도 (없으면 방 버튼만) |
| `tutorial/*.png` | 1000×480 | tutorial.yaml 의 image |
| `phone/*.png` | 128×128 | contacts.yaml 의 icon (발신자 프로필) |

### 화면별로 필요한 UI 요소 (디자인 참고용)

| 화면 | 요소 |
| --- | --- |
| 대화 | 대화창, 이름표, 다음 표시(▼), 의심 버튼, 작은 버튼 줄(오토·스킵·지난 대화·수첩·폰·창 숨기기·설정) |
| 선택지 | 선택지 버튼 (보통 / 마우스 올림 / 비활성), 제한 시간 막대 |
| HUD | 인원 체크 초상화 (보통 / 사라짐=흑백), 의심도 게이지, 수첩·설정 동그라미 버튼, 새 메시지 알림 버튼 |
| 조사 | 조사 지점 강조, "조사 완료" 표시, 아래 이동 막대, 필수 단서 개수 |
| 지도 | 지도 그림, 방 버튼 (현재 / 가 봄 / 안 가 봄) |
| 수첩 | 탭 5개, 증거 카드, 인물 카드 (보통 / 행방불명) |
| 추리 보드 | 보드 틀, 빈칸 (비어 있음 / 채움 / 정답), 카드 고르기 창 |
| 폰 | 폰 틀, 말풍선 (상대 / 나 / 삭제됨), 입력 중, 답장 버튼, 제한 시간 막대 |
| 단톡방 심리 | 채팅 틀, 메시지 (보통 / 선택 / 사라지는 중 / 캡처됨 / 삭제됨), 행동 버튼 4개, 발언권 표시, 귓속말 카드 |
| 여론전 | 캐릭터 카드 (이름, 의심 대상, 확신 점 5개, 성향), 결론 카드 |
| 컷인 | 큰 글자 (반박, 되묻기, 대조, 캡처, 성공, 재판 시작, 판결) |
| 엔딩 | 엔딩 번호, 종류, 제목, 버튼 2개 |
| 갤러리 | 엔딩 칸 (해금 / 잠김) |
| 흐름도 | 지점 (시작 / 장면 / 체크포인트 / 엔딩 / 잠김), 연결선 |
| 알림 | 작은 알림 (보통 / 단서 / 경고 / 호감도 상승) |
