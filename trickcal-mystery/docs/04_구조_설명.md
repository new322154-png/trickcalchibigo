# 구조 설명 (엔진)

작가 작업에는 필요 없고, 기능을 고치거나 추가할 때 보는 문서입니다.

## 흐름

```
content/*.yaml ──(import.meta.glob)──▶ engine/content.ts ──▶ C (전역 콘텐츠)
content/story/*.ink ──(tools/vite-plugin-ink.ts, 빌드 시 컴파일)──▶ engine/story.ts (inkjs)

engine/game.ts  메인 루프
  ├─ story.nextLine() → 태그 실행(applyTags) → 대사 표시(ui/dialogue) → 모드 태그 실행(runDeferred)
  ├─ 선택지 → ui/dialogue.choose()
  └─ 모드: modes/investigation · board · phone · trial/* · ending
          각 모드는 "이어갈 knot 이름"을 돌려주고, game 이 story.goto() 로 이어간다
```

## 파일

| 파일 | 역할 |
| --- | --- |
| `src/main.ts` | 시작점. 콘텐츠 → 상태 → 대본 → 화면 → 타이틀 |
| `engine/content.ts` | YAML 읽기, 형식 정의, `t()`(UI 문구), `names()`(%기능이름%) |
| `engine/state.ts` | 게임 상태 `S`(세이브에 들어감), 영구 기록 `P`(엔딩·체크포인트·읽은 대사·설정) |
| `engine/events.ts` | 이벤트 버스. 상태가 바뀌면 이벤트 → HUD·알림이 반응 |
| `engine/story.ts` | inkjs 래퍼, EXTERNAL 함수 연결, "이름(감정): 대사" 해석 |
| `engine/game.ts` | 메인 루프, 태그 처리, 모드 전환, 의심 표시, 체크포인트, 튜토리얼 |
| `engine/save.ts` | 슬롯 저장·불러오기, 파일 내보내기, 체크포인트 |
| `engine/audio.ts` | 배경음악·효과음 |
| `engine/util.ts` | `waitFor`(취소 가능한 입력 대기), `isTodo` 등 |
| `ui/*` | 무대 크기 맞춤, 배경·캐릭터, 대화창, 창·알림, HUD, 메뉴 화면, 디버그 |
| `modes/*` | 조사, 추리 보드, 폰, 재판(단톡방·역습·여론전), 엔딩 |

## 규칙

- **상태는 반드시 `state.ts` 의 함수로 바꾼다** (`giveClue`, `addAffinity` …). 그래야 이벤트가 나가고 알림이 뜬다.
- **입력을 기다릴 때는 `waitFor()`** 를 쓴다. 불러오기·타이틀 이동 때 `cancelAllWaits()` 가 기다림을 전부 취소해서, 이전 진행이 뒤에서 계속 돌지 않게 한다.
- 세이브 = ink 상태 JSON + `S` + 재개 지점(`Resume`). 재판 중에는 저장을 막고, 재판 시작 직전 체크포인트로만 돌아간다.
- 모드 화면은 `mode` 레이어, 폰·메뉴·엔딩은 `modal` 레이어. 대화창(`dialogue` 레이어)은 모드 위, 모달 아래.

## 새 모드 추가하기 (예: 미니게임)

1. `src/modes/새모드.ts` 에 `export async function runX(id: string): Promise<string | null>` 작성 — 끝나면 이어갈 knot 이름을 돌려준다
2. `engine/game.ts` 의 `DEFERRED` 목록과 `enterMode()` 의 switch 에 한 줄씩 추가
3. 데이터는 `content/새폴더/*.yaml` 에 두고 `engine/content.ts` 의 `loadContent()` 에서 합치기
4. `scripts/check-content.mjs` 에 태그 검사 한 줄 추가 (`case '새태그':`)

## 알려진 한계 / 다음 작업 후보

- 캐릭터 GIF 는 "말하는 모션" 교체만 지원 (프레임 단위 제어는 GIF 특성상 불가 → WebP/스프라이트시트로 바꾸면 가능)
- 재판 페이즈별 BGM, 컷인 이미지, 사건 재구성(만화 칸) 미니게임은 아직 없음
- 교주 이름 입력(`name_input`)은 칸만 있고 입력 화면은 아직 없음
- 폰 대화의 삭제 타이머는 대화창을 닫으면 멈추지 않고 계속 돈다 (의도: 나중에 열면 이미 지워져 있음)
