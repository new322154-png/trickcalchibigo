# 대본 작성 가이드

대본은 [ink](https://www.inklestudios.com/ink/) 라는 스크립트 언어로 씁니다.
분기·선택지·변수를 쓰려고 만든 언어라, 수십만 자 규모의 대본도 파일을 나눠 관리할 수 있어요.

**추천 도구: [Inky](https://github.com/inkle/inky/releases)** (무료 ink 편집기)
`content/story/main.ink` 를 열면 오른쪽에서 바로 미리 플레이할 수 있고, 문법 오류를 줄 단위로 알려줍니다.
게임 화면·연출은 `npm run dev` 로 확인하세요.

## 1. 기본 문법 (이것만 알면 80%)

```ink
=== ch1 ===                 // knot: 큰 장면. 이름은 영문·숫자·_ 만
-> morning                  // 이동

= morning                   // stitch: knot 안의 작은 장면
(지문은 이름 없이 그냥 씁니다)
에르핀: 대사는 "이름: 대사"
에르핀(웃음): 괄호 안에 감정을 쓰면 표정이 바뀝니다
(분노)이름 없이 감정만 쓰면 직전 캐릭터가 표정을 바꿔 이어서 말해요
-> next_scene
```

### 선택지

```ink
* [선택지 A]
    교주: A를 고른 뒤의 대사
* [선택지 B]
    교주: B를 고른 뒤의 대사
-
두 갈래가 여기서 다시 합쳐집니다
```

- `*` 는 한 번 고르면 사라지는 선택지, `+` 는 계속 남는 선택지
- 선택지 뒤의 `-` 줄은 "합류 지점"
- **조건이 있는 선택지**: `* {has_clue("broken_cup")} [컵 얘기를 꺼낸다]`

### 조건 분기

```ink
{ affinity("joan") >= 5:
    죠안: 교주님을 믿어요!
- else:
    죠안: 음… 글쎄요.
}

{ voted():
- "erpin": 에르핀이 지목됐을 때
- "tig":   티그가 지목됐을 때
- else:    그 외
}
```

### 변수 (ink 안에서만 쓰는 값)

```ink
VAR 식기_개수 = 11          // main.ink 맨 위 등에 선언
~ 식기_개수 = 식기_개수 + 1
{식기_개수 > 10: 식기가 하나 많다…}
```

## 2. 이 게임만의 약속

### 게임이 알려주는 값 (조건문에서 사용)

| 함수 | 뜻 |
| --- | --- |
| `has_clue("id")` | 그 단서를 가지고 있나 |
| `has_card("id")` | 그 결론 카드를 가지고 있나 |
| `affinity("erpin")` | 교주 호감도 (숫자) |
| `suspicion()` | 교주 의심도 (숫자) |
| `suspected("id")` | 그 발언(`#suspect:id`)에 의심 표시를 했나 |
| `flag("이름")` | flag 가 켜져 있나 |
| `present("sila")` | 아직 일행에 있나 (사라지지 않았나) |
| `seen_ending("ch1_wrong")` | (회차 기억) 그 엔딩을 본 적 있나 |
| `voted()` | 방금 재판에서 지목된 사람 id |
| `has_item("id")` | 아이템을 가지고 있나 |
| `confined("누구")` | 그 캐릭터가 갇혀 있나 |
| `has_truth("id")` | 진실 조각을 모았나 |
| `knows_habit("누구.습관")` | 그 습관을 알고 있나 |
| `anomalies("누구")` | 그 캐릭터에게서 잡아낸 어긋남 개수 (`""` 이면 전체) |
| `time_now()` | 지금 시간대 (`"morning"` 등) |
| `day()` | 며칠째인가 |
| `impostor()` | 오늘 저택이 변장한 사람 id (`days.yaml`) |
| `was_impostor("누구")` | 그 캐릭터가 한 번이라도 가짜였나 (기억이 빈 사람) |
| `found_today()` | 오늘 가짜를 찾아냈나 |
| `found_day(2)` | 그 날 가짜를 찾아냈나 |

Inky 에서 미리보기할 때는 이 값들이 고정값(`main.ink` 아래쪽)으로 대신 들어갑니다.

### 태그 전체 목록

태그는 `#` 으로 시작하고, **대사 줄 끝에 붙이거나 대사 바로 윗줄에 따로** 씁니다.
윗줄에 따로 쓴 태그는 "바로 다음 대사"에 붙어서, 그 대사가 나오기 직전에 실행됩니다.

**화면·소리**

| 태그 | 예 | 설명 |
| --- | --- | --- |
| `#bg:이름` | `#bg:dining` | 배경 (`assets/bg/dining.png`). `black` = 검은 화면. 배경은 부드럽게 겹쳐 바뀜 |
| `#bg:이름 연출` | `#bg:corridor stairs_up` | 이동 연출과 함께 배경 바꾸기: `zoom`(문으로 확대) `stairs_up` `stairs_down`(계단, 위아래 흔들림) `left` `right`(옆으로 걷기) `fade` |
| `#move:연출` | `#move:stairs_up` | 배경은 그대로 두고 이동하는 움직임만 (걸어가는 느낌) |
| `#fx:종류` | `#fx:rain` | 분위기 입자 — `dust`(촛불 먼지) `rain`(비) `embers`(불티) `none` |
| `#lightning` | | 번개 (번쩍 + 천둥) |
| `#shout` | `네르: 교주님! #shout` | 소리치는 대사 — 크고 굵은 기울임 글씨, 세로 가운데, 대화창이 흔들림 |
| `#cg:이름` | `#cg:ch1_found` | 이벤트 그림. `#cg:none` 으로 닫기 |
| `#show:캐릭터 감정 위치` | `#show:erpin smile left` | 캐릭터 등장/표정/위치. 한글도 됨 `#show:에르핀 웃음 왼쪽` |
| `#hide:캐릭터` | `#hide:erpin` | 퇴장 |
| `#hideall` | | 모두 퇴장 |
| `#shake` `#shake:2` | | 화면 흔들림 (숫자 = 세기) |
| `#flash` `#flash:red` | | 번쩍임 |
| `#fadeout` `#fadein` | `#fadeout:1` | 암전 / 밝아짐 (초) |
| `#wait:초` | `#wait:1.5` | 잠깐 멈춤 |
| `#bgm:이름` | `#bgm:mansion` | 배경음악 (`assets/bgm/mansion.mp3`). `none` = 끄기 |
| `#se:이름` | `#se:thunder` | 효과음 |

위치: `left`, `center`, `right`, `farleft`, `farright` (또는 `왼쪽`, `가운데`, `오른쪽`, 숫자 %)

**상태**

| 태그 | 예 | 설명 |
| --- | --- | --- |
| `#clue:id` | `#clue:broken_cup` | 단서 획득 |
| `#clue_update:id` | | 단서 설명이 바뀌었다는 알림 |
| `#conclusion:id` | | 결론 카드 바로 주기 |
| `#affinity:캐릭터 숫자` | `#affinity:joan +1` | 호감도 변화 |
| `#suspicion:숫자` | `#suspicion:+2` | 교주 의심도 변화 |
| `#flag:이름` / `#unflag:이름` | `#flag:study_unlocked` | flag 켜기/끄기 |
| `#vanish:캐릭터` / `#return:캐릭터` | `#vanish:sila` | 실종 / 귀환 (인원 체크 흑백) |
| `#suspect:id` | `네르: 난 몰라 #suspect:ner_lie1` | **이 발언은 의심 표시 정답**. 태그 없는 발언에 표시하면 오답 처리 |
| `#timer:초` | `#timer:10` | 바로 다음 선택지에 제한 시간. 시간이 지나면 **마지막 선택지**가 골라짐 |
| `#item:id` / `#lose_item:id` | `#item:rusty_key` | 아이템 얻기 / 잃기 (`items.yaml`) |
| `#time:시간대` | `#time:night` | 시간대 바꾸기 (`morning` / `day` / `night`). 조사 중 사람 배치가 바뀜 |

| `#confine:캐릭터` / `#release:캐릭터` | `#confine:ner` | 판결로 갇힘 / 풀려남 (일행 표시에 자물쇠, 조사 중 못 만남) |
| `#truth:id` | `#truth:truth_ch1` | 진실 조각 얻기 (`truths.yaml`) |
| `#habit:캐릭터.습관` | `#habit:erpin.calls_kyoju` | 그 캐릭터의 평소 습관을 알게 됨 (`characters.yaml` 의 `habits`) |
| `#mismatch:캐릭터.습관` | `에르핀: 교주 씨! #mismatch:erpin.calls_kyoju` | **습관과 어긋난 말**. 그 습관을 아는 상태에서 의심 버튼을 누르면 "어긋남"으로 기록 |

**진행**

| 태그 | 설명 |
| --- | --- |
| `#chapter:ch1` | 장 시작 화면 + 자동 저장 |
| `#scene:이름` | 세이브 슬롯에 표시될 장면 이름 |
| `#node:id` | 흐름도 지점을 "지나감"으로 표시 |
| `#checkpoint:id` | 체크포인트 저장 (재판은 자동) |
| `#tutorial:id` | 기능 설명 (처음 한 번만) |
| `#notify:대화id` | 메신저 알림만 띄움 (플레이어가 원할 때 열기) |

**모드 전환** — 태그가 붙은 대사가 끝난 뒤 그 모드로 넘어가고, 모드가 끝나면 yaml 에 적힌 knot 으로 이어집니다.
그래서 모드 태그는 **넘어가기 직전 대사의 끝**에 붙이세요. 윗줄에 따로 쓰면 그 아래 대사까지 나온 뒤에 넘어갑니다.

| 태그 | 이어지는 곳 |
| --- | --- |
| `#investigate:id` | `investigations/*.yaml` 의 `on_complete` |
| `#board:id` | `board/*.yaml` 의 `on_complete` |
| `#trial:id` | `trials/*.yaml` 의 `results` (결과별로 다름) |
| `#phone:대화id` | `phone/*.yaml` 의 `on_end` (비우면 원래 대본으로 복귀) |
| `#ending:id` | 엔딩 화면 → 체크포인트 또는 타이틀 |
| `#accuse` | **지목** 화면. `days.yaml` 의 그날 `on_found` / `on_missed` 로 (비우면 원래 대본으로 복귀) |

```ink
엘레나: 이제 재판을 시작하자. #trial:ch1_trial
-> DONE
```

`#phone` 은 끝나면 원래 자리로 돌아오니 `-> DONE` 없이 이어서 쓰면 됩니다.

### 하루의 흐름 — "저택은 매일 한 명으로 변장한다"

`content/days.yaml` 에 날마다 **가짜(impostor)** 와 **못 찾았을 때 사라질 사람(vanish_if_missed)** 을 적습니다.

1. 그날 대본에서 가짜 캐릭터의 대사에 `#mismatch:누구.습관` 을 심어 둡니다 (습관과 어긋난 말).
2. 조사·사진 비교·대화로 단서를 모은 뒤 `#accuse` 로 지목. (재판의 여론 투표 결과가 가짜와 같아도 "찾음" 처리)
3. 하루를 마칠 때 `#next_day` — 날짜 카드가 뜨고,
   - 오늘 가짜를 **찾았으면** 아무도 사라지지 않음
   - **못 찾았으면** `vanish_if_missed` 가 사라짐 (진짜로 사라짐 — 일행 표시 흑백, 조사에서도 못 만남)
4. 가짜였던 사람은 그 시간의 기억이 없습니다. 대본에서 `was_impostor("sila")` 로 분기해 "기억이 안 나…" 대사를 쓰세요.

```ink
실라: 어? 나 방금 뭐 하고 있었지… 
{ was_impostor("sila"): 실라: 어제 저녁부터 기억이 하나도 안 나. }
엘레나: 오늘은 누굴까. #accuse
-> DONE
=== day1_found ===
저택: …들켰네. 오늘 밤은 조용히 있어 줄게.
엘레나: 하루를 마치자. #next_day
```

**이야기 줄기 지키기** — 줄기는 한 줄로 쓰고, 사람이 빠진 자리만 한 줄 분기로 채웁니다.

- `days.yaml` 의 `protect` 로 꼭 필요한 사람을 그 날까지 보호
- `critical: true` + `bad_ending` : 꼭 맞혀야 하는 날. 틀리면 배드 엔딩 → 그날 아침 체크포인트에서 다시
- 대본 파일(또는 knot) 위에 `// @day 3` 을 적으면, 그날 이미 사라졌을 수 있는 사람이 분기 없이 말할 때 내용 검사가 알려 줌

```ink
// @day 3
{ present("sila"): 실라: 이 그림, 내가 그린 거야. | 엘레나: …실라가 있었다면 알아봤을 텐데. }
```

말하는 사람을 `저택` 으로 쓰면 대화창 없이 **화면 한가운데 붉은 글씨**로 나옵니다 (저택의 목소리).

## 3. yaml 파일 안의 대사

조사·재판·보드처럼 yaml 에 쓰는 대사도 같은 형식입니다.

```yaml
lines:
  - 에르핀(당황): 여, 여기 뭔가 있어!
  - 바닥에 물 자국이 이어져 있다.
  - 교주: 이건…
```

- `- ` 한 줄이 대사 하나
- 줄에 `:` 가 두 번 이상 들어가거나 `#` 이 들어가면 따옴표로 감싸세요: `- "엘레나: 시간은 3:15였어"`
- 여러 줄 설명은 `|` 뒤에 들여쓰기

```yaml
desc: |
  첫째 줄
  둘째 줄
```

### 자동으로 바뀌는 글자

| 쓰는 법 | 바뀌는 것 |
| --- | --- |
| `%notebook%`, `%trial%` … | game.yaml 의 기능 이름 |
| `{name}`, `{target}` … | 게임이 채우는 자리 (ui.yaml, 반응 대사) |

## 4. 자주 하는 실수

| 실수 | 결과 | 해결 |
| --- | --- | --- |
| 대사에 `#` 을 씀 (`#1번 방`) | `#` 뒤가 태그로 사라짐 | `＃` (전각) 이나 `No.1` 로 |
| 대사가 `-` 로 시작 (`- 뭐야?`) | 합류 지점으로 읽힘 | `―` 나 `…` 으로 시작 |
| 합류 지점 바로 뒤에 괄호 (`- (TODO) 대사`) | 괄호 안이 label 로 읽힘 | 합류 `-` 를 따로 한 줄에 쓰고 대사는 다음 줄 |
| 대사에 `{ }` 를 씀 | 조건문으로 읽힘 | `｛ ｝` (전각) 으로 |
| 대사에 `//` 를 씀 (URL 등) | 뒤가 주석으로 사라짐 | `\/\/` |
| knot 이름에 한글 | 오류 | 영문·숫자·`_` 만 |
| `-> DONE` 을 빠뜨림 | 다음 knot 로 흘러감 | 모드 태그 뒤에는 `-> DONE` |
| `이름 : 대사` (콜론 앞 띄어쓰기) | 괜찮음 | |
| `이름: 대사` 에서 이름 오타 | 지문으로 표시됨 | characters.yaml 의 name 과 똑같이 |

## 5. 파일 나누기

- 장마다 폴더 하나 (`story/ch1/`, `story/ch2/`)
- 한 파일이 너무 길어지면 나눠도 됩니다. `main.ink` 에 `INCLUDE` 한 줄만 추가하면 돼요
- knot 이름은 전체에서 겹치면 안 되니 `ch1_`, `ch2_` 처럼 장 이름을 붙이는 걸 추천합니다
