# 작성 체크리스트

어떤 순서로 무엇을 채우면 되는지 정리한 목록입니다.
각 파일 안에는 `# Q:` 질문이 칸마다 달려 있으니, 여기서는 **순서와 큰 결정**만 봅니다.

남은 칸은 언제든 터미널에서 확인할 수 있어요.

```
npm run todo        # 파일별 개수
npm run todo:list   # 파일:줄 · 질문 목록
```

> 순서는 추천일 뿐입니다. 다만 1~3단계(이름, 캐릭터, 사건 설계)를 먼저 정해 두면
> 뒤의 대사를 쓰면서 되돌아가 고칠 일이 줄어듭니다.

---

## 1단계. 게임의 얼굴 — `content/game.yaml`

- [ ] 제목, 부제, 제작자, 타이틀 안내 문구
- [ ] 패러디·팬게임 고지문
- [ ] 크레딧
- [ ] **기능 이름 31개** — 게임 전체 버튼·메뉴·튜토리얼에 자동으로 들어갑니다
  - 조사·추리: 의심 버튼, 수첩(+탭 4개), 조사, 지도, 추리 보드, 결론 카드
  - 휴대폰: 기기 이름(기본: 휴대폰), 단체방, 엿보기, 복구
  - 재판: 재판 전체, 페이즈 3개, 발언권, 행동 4개(되묻기·반박·캡처·대조), 귓속말, 투표, 연장 토론
  - 관계·분기: 호감도, 의심도, 인원 체크, 흐름도, 체크포인트, 갤러리
  - 비워 두면 기본 이름(수첩, 발언권…)이 대신 쓰입니다
- [ ] **컷인 외침 7개** — 역전재판의 "이의 있음!"에 해당하는 화면 가득 뜨는 글자

## 2단계. 등장인물 — `content/characters.yaml`

- [ ] 교주: 화면에 모습이 나오는지, 이름 입력을 받을지, 성격(작가용 메모)
- [ ] 10명 공통 (각자)
  - [ ] 이름표 색
  - [ ] 수첩 인물 소개 (`profile`)
  - [ ] 말투 메모 (`voice_note`, 작가용) — 1인칭, 호칭, 입버릇
  - [ ] 가진 감정 GIF 목록 (`emotions`)
  - [ ] 기본 반응 대사 8종: 괜한 의심, 엿보기 들킴, 설득됨, 흔들림, 역효과, 요지부동, 투표 한마디, 사라졌을 때 메모
- [ ] 감정 번역표에 더 쓸 감정 추가 (놀람, 삐짐 등)

설득 성향과 시작 호감도는 대화에서 정한 대로 들어가 있습니다.

| 성향 | 캐릭터 |
| --- | --- |
| 감정파 | 에르핀, 네르, 티그, 우로스 |
| 증거파 | 엘레나, 아멜리아, 실라 |
| 교주 신뢰파 (시작 호감도 5) | 죠안, 다야, 셰이디 |

## 3단계. 사건 설계 (작가용 메모) — `content/chapters.yaml`

게임 화면에는 안 나오지만, 대사를 쓰기 전에 정해 두면 좋은 것들입니다.

- [ ] 전체 장 수
- [ ] 장마다: 제목, 장 시작 화면 문구
- [ ] 1장: 진범, 트릭 한 줄 요약, 장 끝에 남기는 "저택의 섬뜩한 단서"
- [ ] `content/phone/contacts.yaml`: 메신저의 세계관 설정, 처음 열리는 시점, 발신자 불명 메시지의 흐름
- [ ] `content/locations.yaml`: 저택 방 목록과 층 구조 (예시 방 6개를 바꾸거나 지우기)
- [ ] `content/evidence.yaml`: 1장 단서 목록 (필수 / 선택)

## 4단계. 프롤로그 — `content/story/prologue/prologue.ink`

장면 8개로 나눠 두었습니다. 장면마다 `// Q:` 질문이 있어요.

- [ ] 1 빵주 기내 — 첫 대사, 볼케니카로 가는 이유, 캐릭터 소개 개그
- [ ] 2 난기류와 추락
- [ ] 3 눈을 뜨다 — 누가 교주를 깨우나
- [ ] 4 대저택 발견
- [ ] 5 저택 안으로 — "방금까지 누가 살던 것 같은" 연출, 의심 표시 연습
- [ ] 6 무전기 먹통 — 엘레나
- [ ] 7 머물기로 하다 — 선택지 예시 (호감도 변화)
- [ ] 8 첫날 밤 — 방 배정(1장 알리바이와 연결!), 실라의 마지막 대사

## 5-1단계. 1장 = 튜토리얼 장

1장은 기능을 하나씩 처음 써 보는 장입니다. 기능을 처음 쓰는 순간 `text/tutorial.yaml` 의 설명이 자동으로 뜹니다(기본 문구가 들어 있음).

- [ ] `investigations/ch1.yaml` 의 방탈출 예시(찻잔 클로즈업 → 쪽지·열쇠 → 서랍장 · 금고)를 실제 사건에 맞게 고치기
- [ ] 사람 배치: 방마다 누가 어느 시간대(`time`)에 있는지, 대화 주제(`topics`)와 보여 주기 반응(`present`)
- [ ] `characters.yaml` 의 `habits`(평소 습관) — 캐릭터마다 2~4개. 가짜 찾기의 기준이 됩니다
- [ ] `items.yaml` 아이템, `truths.yaml` 진실 조각
- [ ] 재판 결과: 진범이 갇히는지(`#confine`), 어떤 진실 조각을 얻는지(`#truth`)
- [ ] (선택) 교주 피고 재판: `trials` 에 따로 쓰고 원래 재판의 `if_suspected` 에 id
- [ ] 튜토리얼 문구를 캐릭터 대사로 바꾸고 싶으면 `speaker` 를 캐릭터 id 로

## 작업하다 막히면

| 증상 | 확인할 것 |
| --- | --- |
| 게임 화면에 빨간 오류가 뜸 | 오류에 나온 파일과 줄 번호. 대본이면 대부분 `#`, `-`, `{ }` 문제 (대본 가이드 "자주 하는 실수") |
| 대사가 안 나오고 넘어감 | 이름 뒤에 콜론 `:` 을 빠뜨렸거나, 줄이 `-` 로 시작함 |
| 캐릭터 그림 대신 점선 상자가 뜸 | 파일 이름·확장자 확인. `characters/erpin/smile.gif` |
| 조사 지점을 못 찾겠음 | 디버그 메뉴 → "조사 지점 테두리 보기" 로 rect 위치 확인 |
| 특정 장면만 테스트하고 싶음 | 디버그 메뉴 → 대본 이동 |
| `npm run build` 가 실패함 | `npm run check` 결과의 ✖ 줄 |
